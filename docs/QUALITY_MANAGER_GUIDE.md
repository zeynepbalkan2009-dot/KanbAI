# Quality Manager Guide

## HITL Kuyrugu
HITL paneli REVIEW veya yuksek riskli FAIL sonuclarini listeler. Kalite yoneticisi her kaydi acip dogru etiketi secer.

## Karar Tipleri
- pass: Parca uygundur.
- fail: Defekt dogrulandi.
- wrong_prediction: AI yanlis tahmin yapti.
- needs_retrain: Ornek model egitimine alinmali.

## Dataset Katkisi
Dataset Contribution aciksa karar egitim havuzuna eklenir. Bu KanbAI'nin surekli ogrenme dongusunun ana verisidir.
